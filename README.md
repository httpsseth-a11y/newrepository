# XatSpace — Urban Green

Modelo de perfil pessoal com visual preto e verde-petróleo, usando sua foto.

## Arquivos
- `index.html` — estrutura da página.
- `styles.css` — cores, layout, responsividade e efeitos.
- `script.js` — interação simples do menu.
- `assets/minha-foto.png` — sua fotografia usada no perfil.
- `assets/referencia-visual.png` — imagem de referência do conceito (opcional).

## Como visualizar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para publicar online, envie a pasta para um serviço de hospedagem estática, como GitHub Pages.

## Personalizar
- Troque a foto substituindo `assets/minha-foto.png` por outra imagem com o mesmo nome.
- Edite os textos em `index.html`.
- Mude as cores no início de `styles.css`, dentro de `:root`.

Observação: este é um site responsivo inspirado em um XatSpace. Dependendo do editor/área específica do xat.com, pode ser necessário adaptar o código às limitações de incorporação e aos tamanhos aceitos pela plataforma.
